# 📚 Grupo de História Intelectual: pesquisa e extensão

> Plataforma de acesso a livros, materiais e recursos acadêmicos para membros da comunidade acadêmica.

## 🚀 Tecnologias Utilizadas

- [Next.js](https://nextjs.org/) — Framework React
- [Tailwind CSS](https://tailwindcss.com/) — Estilização
- [Supabase](https://supabase.com/) — Banco de Dados (PostgreSQL) e Armazenamento
- [Vercel](https://vercel.com/) — Hospedagem e Deploy Contínuo
- [Figma](https://www.figma.com/design/eIEpLJeBkrT0g68RMgiIEC/Site-Cronopios?node-id=6-310&t=X0e1AaDAsrN9EJP2-1) — Design da interface

## 📦 Funcionalidades

- 🔍 Busca e acesso a livros e materiais acadêmicos
- 🌗 Tema claro/escuro ajustável pelo usuário
- 📄 Visualização e download de PDFs
- 🔗 Plataforma responsiva (desktop, tablet, mobile)
- 🚧 Página de manutenção "Em construção" (enquanto em desenvolvimento)
